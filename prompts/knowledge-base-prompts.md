# 📚 Knowledge Base Prompts with AI

## Overview

A well-written knowledge base empowers both customers and internal teams to find answers quickly, reduces repetitive questions, and creates a more consistent support experience.

I use AI to accelerate the first draft of documentation while ensuring every article is reviewed, validated, and refined before publication.

> **Note:** AI should assist with documentation—not replace product expertise, customer context, or careful review.

---

# 🎯 Use Cases

Use these prompts for:

- Knowledge Base Articles
- Help Center Documentation
- Standard Operating Procedures (SOPs)
- Frequently Asked Questions (FAQs)
- Internal Process Guides
- Feature Documentation
- Troubleshooting Articles

---

# 🤖 Prompt 1: Create a Knowledge Base Article

```
You are an experienced Customer Success Manager.

Create a customer-friendly knowledge base article.

Include:

- Clear title
- Purpose
- When to use this guide
- Step-by-step instructions
- Tips and best practices
- Common mistakes
- Frequently asked questions
- Related resources

Use simple language and avoid technical jargon wherever possible.
```

---

# 🤖 Prompt 2: Improve Existing Documentation

```
Review the following documentation.

Identify:

- Unclear language
- Missing steps
- Repetitive information
- Opportunities to improve readability
- Suggested headings
- Better formatting

Rewrite the document so it is easier for customers to understand.
```

---

# 🤖 Prompt 3: Generate FAQs

```
Based on the following feature or process, generate Frequently Asked Questions.

For each question include:

- Clear answer
- Common misconceptions
- Helpful tips
- Links to related topics (if applicable)

Write from the customer's perspective.
```

---

# 🤖 Prompt 4: Create an SOP

```
Create a Standard Operating Procedure.

Include:

- Objective
- Scope
- Roles and responsibilities
- Step-by-step process
- Quality checks
- Exceptions
- Success criteria

Write clearly enough that a new team member could confidently follow the process.
```

---

# 💡 Why I Use These

Documentation is one of the most scalable ways to improve the customer experience.

Rather than starting from a blank page, I use AI to organize information into a clear structure, identify gaps, and improve readability.

This allows me to focus more on validating content, incorporating real customer scenarios, and ensuring the documentation is genuinely useful.

---

# ✅ Best Practices

Before publishing documentation, I always:

- Verify every step for accuracy
- Remove unnecessary jargon
- Use customer-friendly language
- Include screenshots or examples when possible
- Test the documented process myself
- Update articles as products or processes evolve

---

# ⚠️ Common Mistakes

Avoid:

- Writing for experts instead of customers
- Skipping important steps
- Using inconsistent terminology
- Publishing AI-generated content without review
- Creating documentation that answers *how* but not *why*

# 🌍 Real-World Example

### Scenario

A support team notices that multiple customers are asking the same question about setting up a new feature.

Instead of answering the same question individually each time, I would use AI to organize the first draft of a knowledge base article.

The AI-generated draft helps structure the content into clear sections, identify missing steps, and suggest customer-friendly language. I then review the article for accuracy, add product-specific details, include screenshots where appropriate, and publish the final version.

### Outcome

Instead of repeatedly answering the same question, the team now has a reusable resource that customers can access whenever they need it.

This improves consistency, supports customer self-service, and allows Customer Success teams to spend more time on higher-value conversations.
---

# Key Takeaway

Good documentation reduces friction, builds customer confidence, and creates consistency across teams.

AI helps me write the first draft faster, but quality documentation always depends on human expertise, thoughtful review, and continuous improvement.

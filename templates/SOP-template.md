# 📋 Standard Operating Procedure (SOP) Template

## Overview

A Standard Operating Procedure (SOP) documents a repeatable process so that tasks can be completed consistently, accurately, and efficiently.

This template can be adapted for Customer Success, Operations, Support, or any process that benefits from clear documentation.

---

# 🎯 Purpose

Use this template to:

- Standardize recurring tasks
- Improve consistency
- Reduce onboarding time
- Support knowledge sharing
- Minimize process gaps
